# K1Blog 视觉与交互设计系统规范

> 文档编号：04  
> 版本：v1.3.9  
> 上游：`00-项目执行宪法`、`03-通用软件工程规范`  
> 视觉基线：生产实现（`app/layout.tsx`、`components/`、`styles/`）  
> 适用范围：品牌、色彩、字体、版式、组件、动效、无障碍、设计验收

## 0. 效力与基准

本文件是 K1Blog 唯一的视觉执行标准。任何 UI、样式、动效、图片、评论界面、管理端的改动，都必须先对照本文件。

生产实现锁定：

- 满屏首页展示场与内容页标题字阶；
- 深色 / 浅色双主题；
- 进度尺、行式列表、编号与状态的仪器语言；
- 120 / 240 / 400 / 600ms 的动效节奏；
- 无阴影、无渐变、无发光、无 AI 模板的克制质感。

最终视觉以本文件与生产验收截图共同确认；禁止引入与内容无关的装饰叙事。

## 1. 概念与设计原则

### 1.1 概念

**低照度写作界面**：以文字为中心，编号、刻度、状态只在边缘工作。深色是默认阅读环境，浅色是另一种阅读状态。视觉保持克制、精密，不使用与内容无关的品牌叙事。

关键词：低照度、编号、刻度、精密、克制。

### 1.2 五条设计法

1. 装饰必须能解释为结构：刻度、索引、坐标、状态；纯装饰删除。
2. 一屏只允许一个主动效焦点；其余靠层级、留白、发丝线建立秩序。
3. 颜色只承担语义，不做氛围渐变；全站只有一个主强调色。
4. 动效只做状态迁移，不做表演；禁止弹跳、发光、光晕堆积。
5. 可读性优先于风格：正文对比度、行宽、行高、触控目标必须先达标。

### 1.3 反模板红线（禁止）

- 蓝紫渐变、霓虹青紫、发光描边、光晕堆叠；
- 玻璃拟态卡片堆叠、超大圆角、悬浮大阴影、浮起卡片；
- 通用 Hero：居中大标题 + 副标题 + 双按钮；
- Bento 拼贴、卡片网格、通用产品官网布局；
- AI 插画、3D 漂浮物、emoji 图标、通用图库拼贴；
- 故障艺术、扫描线、HUD 边框、终端绿、星空、铬字；
- 按钮波纹、幕布升起、弹跳弹簧、无依据的无限动画；
- 表单预填真实或示例敏感数据、与功能无关的占位说明文案。

## 2. 标识

### 2.1 导航入口

- 页头不设品牌字标、图形标志或字母标识。
- 主导航固定在页头右侧，与时钟、主题切换同组；四项功能入口：首页 / 归档 / 关于 / 搜索。
- 导航是胶囊分段控件：等宽编号 + 中文标签，11px；当前项使用实心药丸底反白。
- 胶囊容器使用 1px 发丝边与全圆角；该圆角仅属于导航，不扩散为通用大圆角卡片。
- 触控命中区不得小于 44×44px。

### 2.2 站点名称

- 站点不设中文品牌名、英文副名或字标；页面标识一律使用功能名称。
- 页脚铭牌使用 `博客`，年份可用罗马数字 `MMXXVI`，但不得作为唯一日期表达。
- 浏览器标签图标使用部署者提供的站点图标，透明底，不承载文字品牌。

### 3.3 使用规则

- 强调色只做编号、当前态、关键下划线、状态线；全站占比 ≤ 5%。
- 琥珀不得用于大段正文；浅色下小号琥珀文字必须使用 `#8F5A1A`，不得使用更浅的琥珀。
- 颜色必须承担语义：成功、错误、警告、当前态、禁用态各有固定 token；不得凭视觉喜好换色。
- 禁止线性/径向颜色渐变、发光、彩色阴影；允许硬停刻度纹样（进度尺）与静态胶片颗粒，它们是结构/纹理，不是氛围渐变。
- 两套主题必须成对定义、成对验收；新增 token 必须同时提供深色与浅色值。
- 组件内禁止裸 hex；只允许使用语义 token。确需局部测量色时，必须进 token 文件并经过设计评审。

### 3.4 纹理

- 胶片颗粒：静态 SVG `feTurbulence`，深色 5%、浅色 3.5%，`soft-light`，不随滚动动画。
- 颗粒不得覆盖正文到影响可读性的程度；不得使用动态噪点视频或逐帧噪点。
- 图片采用双色/低饱和处理（琥珀-骨白或氧化蓝-骨白）；图注使用等宽元数据与帧号。

## 4. 字体系统

### 4.1 字族

| 角色 | 字族 | 用途 |
| --- | --- | --- |
| 展示 | Newsreader + 思源宋体展示子集（Noto Serif SC） | 巨型标题、栏目名、文章标题 |
| 正文 | 系统中文黑体（PingFang SC / Microsoft YaHei / Noto Sans CJK） | 正文、导航、说明；不加载全量中文黑体 |
| 元数据 | IBM Plex Mono | 编号、日期、读数、标签、页脚 |

- Newsreader 可使用 200–800 可变字重；正文中文使用 400，标题 400；暗底禁止 300 以下细字重。
- 禁止 `font-synthesis` 伪造斜体/粗体；需要的字重必须真实加载。
- 全站最多三套字族；不得引入第四套装饰字体。
- 中文正文使用系统中文黑体；中文标题使用思源宋体展示子集；禁止用楷体/手写体承担正文。
- 展示字体只覆盖当前标题、栏目名与页面显示文案；新增标题或栏目字符后必须运行 `pnpm fonts:build` 重新生成，不得静默回退到系统宋体。

### 4.2 字号与行高

| 层级 | 字号 | 行高 | 字距 | 说明 |
| --- | --- | --- | --- | --- |
| 展示场标题 | 无可见巨型标题 | — | — | 首页 `h1` 使用 `sr-only`，只为语义与无障碍保留 |
| 栏目标题 | `clamp(36px, 4.2vw, 62px)` | 1.0 | -0.02em | 文章列表等 |
| 文章标题 | `clamp(34px, 4vw, 56px)` | 1.05 | -0.02em | 文章页 |
| 小标题 H2 | `clamp(24px, 2.4vw, 34px)` | 1.25 | -0.01em | 正文分节 |
| 小标题 H3 | `clamp(20px, 1.8vw, 24px)` | 1.3 | 0 | 正文分节 |
| 正文 | 17px | 1.85–1.9 | 0 | 单行 38–40 个汉字 |
| 导语 | 17–20px | 1.9 | 0 | 最大宽度 25em |
| 英文斜体引子 | `clamp(18px, 1.7vw, 24px)` | 1.3 | 0.01em | Newsreader Italic |
| 导航 | 11px | 1.4 | 0.08em | 中文无衬线 |
| 元数据/编号 | 9px | 1.4 | 0.14–0.20em | 等宽大写；中文编号可用 9px |
| 按钮/CTA | 13px | 1.5 | 0.08em | 不用全大写中文 |

- 正文最小 17px；元数据最小 9px；任何 9px 文本必须满足对比度门槛。
- 中文标题不得人为拉开字距；英文元数据可加大字距。
- 数字使用等宽数字（`font-variant-numeric: tabular-nums`），保证读数、日期、时间不抖动。
- 中文标点使用全角；英文与数字使用半角；中英混排保持一个空格。

### 4.3 字体加载

- 展示字体本地自托管并生成站点子集：`noto-serif-display.woff2`（约 20KB）+ Newsreader 子集 + Plex Mono。
- 正文使用系统中文黑体，不再加载 Noto Sans 全量切片；首屏字体实际加载目标 ≤ 80KB，硬上限 220KB。
- 展示字体使用 `preload` 1 个文件；使用 `font-display: optional`，避免慢网络下的迟到换字与 LCP 更新。
- 展示字体子集必须覆盖当前标题、栏目名与页面显示文案；新增标题字符后运行 `pnpm fonts:build`。
- 字体加载不得造成明显布局偏移；不得用 `font-size-adjust` 掩盖设计问题。
- 字体策略的完整背景与代价见 `docs/adr/ADR-0002-font-performance.md`。

## 5. 版式与布局

### 5.1 栅格

- 12 栏只用于内容页与文章列表；首页展示场以视口为骨架，文本区最大 1120px，不居中。
- 页边距：`clamp(20px, 3.2vw, 48px)`；左侧阅读进度尺占 88px（视口 ≥ 1101px）。
- 垂直节奏 8px 基准；关键间距使用 8 的倍数。
- 首页不设居中最大宽度容器；版式锚定视口与左右结构线，大屏保持留白，不强行拉伸。

### 5.2 全站骨架

1. 顶部 masthead：72px；右侧胶囊导航、时钟、主题切换；底部 1px 发丝线。
2. 左侧阅读进度尺：刻度、章节编码、阅读进度；1100px 以下隐藏。
3. 首页 Hero：满屏展示场；指针发丝场、引导 CTA、语义标题；不出现文章列表、最新文章面板或可见巨型标题。
4. 内容页文章列表：行式台账，不是卡片网格。
5. 页脚铭牌：站点名、年份、日期、在线状态。

### 5.3 首页展示场

- 首页只做展示与引导，不渲染文章列表、最新文章面板或文章摘要。
- 背景是 Canvas 2D 发丝场（`Field`）：16–64 根竖向发丝线，每 4 根带横向刻度；指针接近时线条位移、刻度增长，最近一根转琥珀，指针处绘制十字准星。
- 指针坐标在右上角以等宽读数呈现（`X 0120 / Y 0450`）；指针离开后保留最后读数。
- 左上 eyebrow：`WRITING / 2026`，等宽 9px，字距 0.2em。
- 首页不显示巨型标题；`h1` 使用 `sr-only`，只保留语义与无障碍标题。
- 英文斜体引子与导语作为首屏主要文字层级；不使用阶梯标题或标题视差。
- CTA：`浏览全部文章` + 编号 + 箭头，底部发丝线；不重复放置导航已有的入口。
- 底部：左侧 `MOVE / 移动指针校准界面`，右侧 `THEME / LIGHT & DARK`。
- 禁止居中大标题、双按钮、背景大图、透明玻璃卡片、文章卡片或虚构读数。

### 5.4 文章列表

- 标题 `全部文章` + eyebrow `WRITING / ALL`；右侧 `003 POSTS` / `按年份 / 月份排列`。
- 行式台账：编号 64px、标题弹性、元数据 180px、箭头 24px；行高约 96–120px。
- 行分隔线 1px；悬停时顶部浮出琥珀线，标题右移 8px，箭头出现。
- 标签 `[ 技术 ]` 等用等宽 9px，次墨色；不得使用彩色胶囊标签。
- 触屏设备箭头常显 55% 透明度；不得依赖悬停才能发现可点击。

### 5.5 文章页

- 文章头是信息卡：编号、日期、阅读时长、标签、状态标记；不是通用大标题 + 副标题。
- 正文单栏，38–40 汉字/行；左侧可放阅读进度尺/章节编码；右侧留白。
- 目录是纵向胶片格，当前格用琥珀刻度，不使用圆点列表。
- 文章末尾：作者铭牌、更新日期、相关文章列表。
- 评论区是行式列表，不是卡片堆叠；详见第 8 节。

### 5.6 断点

| 断点 | 行为 |
| --- | --- |
| ≥ 1201px | 完整版式：进度尺、胶囊导航、满屏展示场 |
| 1101–1200px | 进度尺保留；胶囊导航略收窄 |
| 1025–1100px | 进度尺隐藏；展示场保持满屏 |
| 721–1024px | 单栏；胶囊导航收窄；Hero 仍满屏 |
| ≤ 720px | 64px 页头；时钟隐藏；胶囊四项压缩；标题 `clamp(80px, 24vw, 160px)`；触控目标放大 |

任何断点都不得出现横向滚动、文字裁切、重叠、不可点击的触控目标。

## 6. 组件语言

### 6.1 导航与链接

- 主导航是右侧胶囊分段控件：四项等宽，当前项使用实心药丸底反白；编号 + 中文标签 11px。
- 悬停或键盘聚焦时，药丸先滑向目标项，文字延迟 200ms 反白，避免滑动中读到反色文字。
- 药丸位移 420ms `cubic-bezier(0.32, 0.72, 0, 1)`；只做位置迁移，不做回弹、缩放或发光。
- 当前项由路径决定并保留 `aria-current="page"`；悬停预览不得改变页面语义。
- 页内链接：骨白文字 + 1px 下划线，偏移 0.2em；悬浮时颜色转琥珀。
- 禁止默认蓝色链接、禁止发光边框；除主导航外不得新增胶囊背景。

### 6.2 按钮

- 直角，1px 发丝描边，背景透明；悬浮为平面底色切换，120ms。
- 无阴影、无渐变、无发光、无波纹、无上浮、无幕布升起。
- 主操作可用琥珀底色 + 夜色文字；次操作用描边；危险操作只用红色文字直陈，不加底色框。
- 主题切换按钮：44×44px 命中区，仅显示太阳 / 月亮线性图标，无边框、无底色；带 `aria-pressed` 与动态 `aria-label`。
- 处理中禁用并显示明确状态；`cursor: not-allowed`；不得只靠颜色变化。
- 按钮文字不得全大写中文；英文可用等宽大写。

### 6.3 标签与编号

- 标签：`[ 观测 ]`、`[ 技术 ]`、`[ 时间 ]`；等宽 9px；次墨色；悬浮转琥珀。
- 编号：`001`、`002`；等宽；琥珀；不参与正文语义。
- 禁止彩色胶囊、圆角标签、emoji、图标装饰。

### 6.4 输入与表单

- 默认完全空白：不预填真实或示例敏感数据；不显示与功能无关的占位说明。
- 标签必须可见；输入框 1px 发丝边；聚焦 2px 琥珀描边，无光晕。
- 错误：字段下方红色文字直陈；不加底色方框、不加图标；同时提供 `aria-describedby`。
- 留言表单可见字段：昵称、留言、提交按钮；蜜罐字段由实现隐藏，不呈现给用户。
- 人机验证启用时使用独立区块，遵守同一套描边、留白与状态语言；不得引入第三方默认主题或大色块。
- 禁用/提交中：`cursor: not-allowed`；按钮显示实际状态；不得重复提交。
- 表单不得自动聚焦到敏感字段；不得在客户端缓存明文敏感数据。

### 6.5 指针场与读数

- `Field` 使用 Canvas 2D：DPR 上限 2，`ResizeObserver` 响应尺寸，主题切换时重读 `--faint` 与 `--amber`。
- 指针移动才启动 rAF，衰减到阈值后停止；不做常驻动画循环。
- 发丝线只使用 `--faint` 与 `--amber`，alpha 由指针距离决定；不使用渐变、发光或粒子。
- 减少动效：不绑定指针事件，只绘制一次静态场；隐藏坐标读数与 `MOVE` 提示。
- 不引入 WebGL、着色器或动画库；坐标读数只是等宽文本，不做滚动跑马灯。
- Canvas 使用专用类名 `.field-canvas`（组件名 `Field`），不得占用表单输入容器的 `.field` 类名；新增全局类名必须带域前缀。

### 6.6 阅读进度尺

- 左侧 1px 细刻度每 12px，主刻度每 60px；琥珀进度线 + 3px 方形标记。
- 进度按 1/40 离散跳变，120ms 线性；不做连续发光进度条。
- 滚动监听 passive + rAF；减少动效时停止过渡。

### 6.7 目录、分页与 Toast

- 目录：纵向胶片格，编号 + 标题；当前格琥珀刻度；不使用圆点/编号圆圈。
- 分页：默认固定每页条数；当前页只用琥珀刻点与实字重，不使用白色方块背景；无阴影。
- Toast：薄磨砂玻璃、1px 发丝边、琥珀状态线、无发光无投影；同一时刻最多一个；3–5 秒自动消失；可手动关闭；键盘可达；文本直陈，不堆形容词。

### 6.8 Dialog、评论与代码块

- Dialog：夜色/纸色表面、1px 发丝边、背景遮罩；不使用大阴影；焦点陷阱；ESC 关闭；标题与关闭按钮可访问。
- 评论：行式列表，发丝分隔；编号、昵称、时间、正文、回复入口；待审状态明确；已删除不显示；不使用卡片。
- 代码块：`#08090A` 底、1px 发丝边、行号次墨、语法色限制在琥珀/骨白/氧化蓝；复制按钮 120ms 平面反馈；禁止霓虹语法主题。
- 表格：发丝行分隔，无粗重底色；数字右对齐、等宽；表头可使用等宽 9px。

### 6.9 图片、空状态与 404

- 图片：双色/低饱和、静态颗粒、图注含帧号/坐标；禁止 AI 插画、3D 漂浮物、通用图库拼贴。
- 空状态：用直陈语言说明「暂无记录」，不使用插画、emoji、卡通角色。
- 404：使用“页面不存在”直陈语言 + 返回首页；不使用通用插画、搜索框堆叠。
- 加载状态：用刻度/扫描线语言；不使用旋转圆环、跳动三点、通用骨架屏堆叠。

### 6.10 管理端自动化控制台

- 控制台沿用仪器语言：策略修订、运行状态、24 小时自动发布/拦截读数以等宽大写呈现，不使用卡片、图表库或彩色仪表盘。
- 度量条为四格发丝分栏；数字等宽 tabular-nums，大号读数只承载一个指标，不在数字后堆叠说明。
- 参数表单使用可见标签、1px 发丝输入框、秒/分钟/条单位；复选框使用方形命中区与语义标签，不使用胶囊开关。
- 参数固定为两个面板：判定阈值（含风险刻度）与节奏、来源与词表；桌面两列排布，单面板 1px 发丝边、无阴影、无大圆角，间距 12–16px。
- 面板头使用琥珀编号 01/02 + 中文标题 + 等宽英文代码；数值字段使用紧凑读数据，宽度按内容取值，禁止铺满整行。
- 参数修改后 600ms 自动保存，不设保存按钮；页眉只保留 REV 与保存状态，状态用等宽 9px 直陈。
- 拦截动作使用短分段按钮，不使用通栏下拉框；选项状态用琥珀文字与 1px 底线表达。
- 风险刻度并入判定阈值面板：0–100 横轴、10 分段刻度、发布/待审/拦截三段线；不使用渐变、发光或彩色填充。
- 词表默认折叠为带计数的按钮，点击打开模态窗口编辑；词项使用「、」分隔，支持 CSV/TXT 导入预览与追加/替换；弹层使用 1px 发丝边、遮罩与无阴影表面。
- 留言台账为行式列表，发丝分隔；每行包含编号、作者与来源、正文、自动判定/风险分/原因、状态与人工兜底操作。
- 台账固定高度内滚动，筛选与分页常驻；长留言默认折叠为 2–3 行，可展开全文，禁止让列表随留言数量无限拉长。
- 自动判定使用 `AUTO`，人工处置使用 `MANUAL`；状态文字直陈，待审用琥珀、拒绝/垃圾用危险色，不使用彩色状态胶囊。
- 所有按钮直角、透明底、1px 描边；分页禁用态使用 `cursor: not-allowed`；不使用阴影、波纹、弹跳或幕布效果。
- 390 / 768 / 1440 / 1920 四档不得横向溢出；移动端台账按编号、正文、状态、操作顺序换行，触控目标 ≥44px。

## 7. 动效系统

### 7.1 Token

| Token | 值 | 用途 |
| --- | --- | --- |
| `d1` | 120ms | 悬浮、颜色、下划线、刻度标记 |
| `d2` | 240ms | 导航线、标题位移、箭头出现 |
| `d3` | 400ms | 常规揭示、读数切换 |
| `d4` | 600ms | 页面迁移、主题擦除 |
| `ease` | `cubic-bezier(0.2, 0.7, 0.1, 1)` | 全站统一曲线 |

- 主题切换：600ms 从右向左裁剪擦除（View Transitions）；不支持时即时切换。
- 首屏文字：eyebrow、引子、导语、CTA 以 400ms 阶梯揭示；首帧文字可见，避免 LCP 延迟。
- 导航药丸：420ms `cubic-bezier(0.32, 0.72, 0, 1)`；文字反白延迟 200ms。
- 指针场：位移、刻度与透明度随指针距离衰减；停止移动后自然收敛，不播放独立动画。
- 底部场提示点：3s 脉冲是唯一无限动画；减少动效时隐藏。

### 7.2 约束

- 只动画 `transform`、`opacity`、`clip-path`；禁止动画宽高、margin、top/left。
- 禁止滚动监听内直接布局读取；必须 passive + rAF。
- 禁止默认弹簧、弹跳、回弹、发光脉冲、呼吸灯。
- 一屏最多一个主动效焦点；页面迁移不得叠加多个独立动画。
- 动效不得阻塞输入；交互反馈必须在 120ms 内出现。
- 任何动效必须有减少动效路径；减少动效下内容完整、无空白、无裁切。

## 8. 内容呈现

- 文章头：编号、发布日期、更新日期、阅读时长、标签；不显示装饰性大图。
- 正文：17px / 1.85，38–40 汉字/行；段落间距 1.2em；引用块左侧双线 + 编号；列表使用方形刻度而非通用圆点。
- 图片：宽度不超过正文测量宽度；图注等宽 9px，包含帧号/来源；无图注的装饰图不得进入正文。
- 脚注：编号与文章编号体系一致；可点击返回。
- 评论：行式列表、编号、时间、正文；回复缩进最多一级；审核状态明确；不显示邮箱/IP。
- 标签/归档：台账行，不使用卡片；标签可在文章头与列表复用。
- 分享图：使用同一套字体、色板、编号；禁止第三方模板。

## 9. 无障碍

- 目标 WCAG 2.2 AA；正文对比度 ≥ 7:1，辅助 ≥ 4.5:1。
- 所有交互键盘可达；焦点可见，2px 琥珀描边，offset ≥ 3px；不得移除 `:focus-visible`。
- 触控目标 ≥ 44×44 CSS px；小号文本链接需扩大点击区域。
- 图标按钮必须有 `aria-label`；装饰 SVG 与 Canvas `aria-hidden`；不提供无意义的方位/罗盘控件。
- 胶囊导航保留真实链接语义与 `aria-current="page"`；滑动的药丸与坐标读数只是装饰，必须 `aria-hidden`。
- 主题切换是可访问按钮，带 `aria-pressed` 与动态 `aria-label`；不得只靠图标。
- 评论表单标签、错误、状态均有可访问关联；错误使用 `aria-describedby`。
- 时钟、读数不得使用会持续打扰的 `aria-live`；必要时提供静态值。
- 减少动效、放大字体、高对比度模式下布局不得崩溃；内容不得被裁切。
- 页面必须有 landmarks、跳转链接、唯一标题、合理标题层级。

## 10. 性能预算

| 项 | 预算 |
| --- | --- |
| 首屏 JS | 目标 ≤ 160KB gzip；门禁 ≤ 180KB gzip |
| 首屏字体 | 目标 ≤ 80KB；硬上限 ≤ 220KB |
| 单图 | ≤ 200KB；AVIF/WebP |
| 单页总重量 | 目标 ≤ 1.2MB |
| LCP | 目标 ≤ 2.5s；门禁 ≤ 2.8s（Lighthouse 移动配置） |
| INP | 目标 ≤ 100ms |
| CLS | ≤ 0.05 |
| 动效 | 仅合成属性；无滚动逐帧重绘 |

- 禁止首屏引入图表、编辑器、3D、重型动画库；Hero 只使用轻量 Canvas 2D 与少量 JS。
- 若未来引入 WebGL/着色器，必须动态加载、首屏降级、减少动效关闭、单独性能评审。
- 字体、图片、动效预算与 `06` 的门禁一致。

## 11. 设计验收矩阵

每次 UI 改动必须提供以下证据：

| 维度 | 要求 |
| --- | --- |
| 宽度 | 390 / 768 / 1440 / 1920 |
| 主题 | 深色 + 浅色 |
| 动效 | 正常 + `prefers-reduced-motion: reduce` |
| 交互 | 悬浮、聚焦、激活、禁用、加载、错误、空状态 |
| 版式 | 无横向溢出、无遮挡、无文字裁切、无布局抖动 |
| 对比度 | 正文/辅助/强调均达标 |
| 无障碍 | 键盘走查、焦点可见、语义与标签正确 |
| 反模板 | 对照第 1.3 节逐项确认 |
| 性能 | 首屏 JS/字体/图片预算与 Lighthouse |

截图与指标必须可复现；不得用旧截图替代新改动。

## 12. Token 治理

- 生产 token 命名建议：`--color-bg`、`--color-text`、`--color-body`、`--color-muted`、`--color-faint`、`--color-accent`、`--color-rule`、`--color-overlay`、`--space-*`、`--type-*`、`--motion-*`、`--radius-*`、`--z-*`。
- 生产 token（`--bg`、`--text` 等）为语义 token；不得在组件里再引入第二套命名。
- 新增/修改 token 必须同时更新两套主题、对比度记录与设计验收。
- token 语义变更（如强调色用途、状态色）必须走 ADR 与设计评审，不得作为普通样式改动。
- 组件不得直接读取基础色值；只消费语义 token。

## 13. 生产落地映射

- `styles/tokens.css`：定义两套主题 token、字阶、间距、动效、层级。
- Tailwind v4：通过 `@theme` / CSS 变量映射 token；组件使用语义类，禁止裸值。
- `components/ui`：手写原语与组合组件；Radix 仅用于 Dialog/Popover 等无障碍原语，外观自建。
- `components/motion`：封装动效 token 与减少动效行为。
- `components/layout/site-nav.tsx`：右侧胶囊导航；`components/layout/field.tsx`：首页指针场与坐标读数。
- 首页/文章页/列表/评论/管理端按本文实现；不再维护独立视觉样张。
- 字体管线：本地展示字体子集 + 系统中文正文 + 首屏预算；禁止整包中文字库。
- 设计系统落地后，`DESIGN_SYSTEM.md` 作为实现索引；本文保持为规范源。

## 14. 设计评审门禁

- 任何 UI PR 必须附第 11 节矩阵的截图与结论；缺少即阻断合并。
- 视觉改动必须对照本文件与生产实现，不得恢复已废弃的品牌叙事或无关装饰。
- 禁止用「看起来更高级」作为理由；必须指向结构、可读性、一致性或性能收益。
- 设计评审不通过时，先修再合并；不得以「后续统一」保留临时样式。
- 任何引入新组件、新 token、新字族、新动效的改动，必须更新本文或新增 ADR。
